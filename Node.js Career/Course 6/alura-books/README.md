# Alura Books

Projeto desenvolvido no **Course 4** da trilha **Node.js Career**.

O app é uma vitrine de livros em React com busca, destaques e recomendações para leitura.

## Tecnologias

- React 19
- Create React App
- styled-components

## Funcionalidades

- Listagem dos últimos lançamentos
- Bloco de recomendação de leitura
- Busca de livros por título
- Layout responsivo com cards centralizados

## Como executar

```bash
npm install
npm start
```

Depois abra [http://localhost:3000](http://localhost:3000) no navegador.
