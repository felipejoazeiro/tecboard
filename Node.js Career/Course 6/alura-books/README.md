# Alura Books

Projeto desenvolvido no **Course 6** da trilha **Node.js Career**.

Este é o projeto do curso **React e Node.js: Consumindo APIs no React no projeto fullstack**. O app evolui a vitrine de livros para consumir APIs locais de livros e favoritos, com navegação entre páginas e gerenciamento de favoritos.

## Tecnologias

- React 19
- Create React App
- React Router DOM
- Axios
- styled-components

## Funcionalidades

- Listagem dos livros consumidos da API
- Busca de livros por título
- Visualização e remoção de favoritos
- Navegação entre a home e a tela de favoritos
- Layout responsivo com cards centralizados

## Como executar

```bash
npm install
npm start
```

Depois abra [http://localhost:3000](http://localhost:3000) no navegador.

Observação: o projeto consome as APIs locais de livros e favoritos, então elas precisam estar em execução em `http://localhost:3001/livros` e `http://localhost:8000/favorites`.
