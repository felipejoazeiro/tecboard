# Python para Dados — Fundamentos de Data Science

Projeto de estudos do curso **Python para Data Science** na [Alura](https://www.alura.com.br), voltado para as bases da programação Python aplicadas à Ciência de Dados.

---

## Tecnologias utilizadas

- Python 3
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## Tópicos estudados

### Python para Dados
- Estruturas de dados nativas: listas, dicionários, tuplas e sets
- Compreensão de listas (list comprehension)
- Funções built-in úteis para dados: `zip()`, `enumerate()`, `map()`, `filter()`

### Introdução ao NumPy
- Arrays e operações vetorizadas
- Estatísticas descritivas básicas

### Introdução ao Pandas
- Criação e manipulação de Series e DataFrames
- Leitura de dados e primeiras explorações

### Visualização com Matplotlib
- Criação de gráficos de linha, barra e dispersão
- Customização de títulos, eixos e legendas

### Análise exploratória
- Identificação de padrões nos dados
- Estatísticas descritivas completas
- Tratamento inicial de dados faltantes

---

## Como executar

```bash
jupyter notebook Projeto_Python_Data_Science.ipynb
```
