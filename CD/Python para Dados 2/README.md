# Python para Dados 2 — Análise e Visualização

Projeto de estudos do curso **Python para Data Science 2** na [Alura](https://www.alura.com.br), com foco em aprofundar as técnicas de análise e visualização de dados com Python.

---

## Tecnologias utilizadas

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Tópicos estudados

### Manipulação avançada com Pandas
- Operações de merge e concatenação de DataFrames
- Agrupamentos com `groupby` e múltiplas funções de agregação
- Tratamento de dados temporais com `pd.to_datetime()`
- Reindexação e transformação de estruturas

### Visualização com Matplotlib e Seaborn
- Gráficos de distribuição: histograma, boxplot, violinplot
- Gráficos relacionais: scatter plot, heatmap de correlação
- Customização avançada de gráficos
- Subplots com `plt.subplot()`

### Análise estatística
- Correlação entre variáveis com `.corr()`
- Detecção de outliers
- Análise de distribuições

### Boas práticas em Data Science
- Organização de notebooks para análise reproduzível
- Documentação de etapas da análise

---

## Como executar

```bash
jupyter notebook projeto.ipynb
```
